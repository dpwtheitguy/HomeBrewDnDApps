# Shared visual and navigation direction

User requests a close visual and navigation reference to Baldur's Gate 3, adapted to the Galaxy Tab A 8.0. Apply this across the planned Complete Guide apps and Arms and Equipment Guide. This document describes shared direction. Arms and Equipment Guide has its own implemented catalog browser.

Use dark slate and warm charcoal surfaces, aged gold borders, inset panels, restrained ornamental corners, pale body text, serif display headings and readable sans-serif explanatory text. Equipment rarity appears as both color and a written label. Show the character portrait, equipment silhouette/paper doll, square inventory slots, carry weight, currency, sortable categories and a compact action bar. Class identity changes accent details and actions while navigation, catalog data and character exchange remain shared.

Landscape inventory: character/equipment at left, inventory grid in the center, pinned item information at right. Portrait: equipment overview above the grid; item information opens in a bottom sheet and can expand to full screen. Preserve filters and scroll position on Back. Use a minimum 48dp interaction target and scalable text; do not copy desktop-sized targets into the tablet UI.

Tap once to inspect. A separate Equip/Use/Roll button commits an action. A long press offers contextual commands; everything on that menu is also available without long press. Item comparison presents equipped and inspected items together. Equip slots highlight compatible items. A visible explanation describes the consequence of missing proficiency; possession is still allowed. Android Back dismisses the deepest sheet, then returns to the previous screen. No hover-dependent explanations.

Every item/ability has a concise headline and TLDR, then mechanics, source/edition, and creative uses. Display action cost, range, save/DC, recharge, remaining uses and relevant proficiency. Visually distinguish official source rules, 2024 adaptation and optional BG3-inspired enhancement. Source and revision information belong in the details, not on every primary button.

Use downloaded reusable generic item-type artwork first. Item-specific artwork is an override with its own author, source and reuse terms. Original styling and icon composition can evoke BG3; downloaded game assets remain references until cleared for the app.

Character versions appear as a journal/history view, with named saves, comparison and restore-as-new-revision. Dice results should remain legible and immediate; costly animations are optional. Merchant screens show the acting character's Persuasion, trader attitude, selected economy policy, base value, buy quote and sell quote. Always label estimates.

Search is a top-level inventory workflow: visible search box, category tabs, sortable grid/list, a touch-friendly filter drawer, active chips, result count, and saved campaign/character presets. Typed setting/region/culture/people facets must show their relationship and evidence. Keep unknown attribution explicit. See SEARCH-AND-RESEARCH.md for implemented search behavior and outstanding Android controls.
